## AI & Code Assistants

- [Claude Code Subscription](https://www.anthropic.com/claude) - Advanced AI assistant for coding, debugging, and technical problem-solving
- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer that helps you write code faster
- [Cursor](https://cursor.sh/) - AI-first code editor built on VS Code
- [v0 by Vercel](https://v0.dev/) - AI-powered UI generation from text prompts
- [ChatGPT](https://chat.openai.com/) - General-purpose AI assistant for brainstorming and problem-solving
- [Tabnine](https://www.tabnine.com/) - AI code completion tool for multiple IDEs

## Backend & Database

- [Supabase](https://supabase.com/) - Open-source Firebase alternative with PostgreSQL database, authentication, and realtime subscriptions
- [Firebase](https://firebase.google.com/) - Google's platform for building web and mobile apps with database, auth, and hosting
- [PlanetScale](https://planetscale.com/) - MySQL-compatible serverless database platform
- [Neon](https://neon.tech/) - Serverless Postgres with branching and autoscaling
- [Railway](https://railway.app/) - Platform for deploying apps with databases and services
- [Convex](https://www.convex.dev/) - Backend platform with real-time database and serverless functions
- [Xata](https://xata.io/) - Serverless database with full-text search and analytics built-in
